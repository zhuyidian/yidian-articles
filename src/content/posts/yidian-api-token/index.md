## 勤开新对话（避开最大的烧钱坑）

*如果您在一个对话框里一直聊，它每次都会把前面的“所有聊天记录”重新阅读一遍并疯狂扣费！ *

**绝招：**解决完一个Bug 或写完一篇文章或代码，**立刻新建对话(New Chat)**，绝不拖泥带水！

## 加上“闭嘴指令”（避免昂贵的输出费）

*Claude 非常有礼貌，每次给完代码还要附赠几十句废话解释，而这些输出全是按高价收费的！ *

**绝招：**在提问最后永远加上一句：**“只输出最终代码/结果，不许做任何解释说明，不要废话。”** 瞬间省下大量的成本！

## 巧用英文提问（天生自带省钱 BUFF）

*因为底层算法的字词切割原因，算力对中文的计费通常比纯英文贵的。*

**绝招：**遇到写代码或者不需要极高中文语境的基础任务时，直接用英文下指令，先天省钱30% 以上！

## 杀鸡不用牛刀（高性价比切模大法）

*别不管干啥都挂着最贵的opus模型！*

**绝招：** 写复杂代码、深度逻辑分析用最强的opus；普通的文字润色、翻译、简单格式排版，请果断切换到Haiku（如果感觉不够用就切换到sonnet）。Haiku 同样聪明，但价格只有前者的几分之一！

## 加装Skills（Agent 的 进阶玩法）

*某些使用场景下，加装对应的Skills，能让AI更强大。*

**绝招：** 比方说处理 Word / Excel / PPT / PDF 的时候，可以通过加装额外的Skills（技能/工具），来方便AI处理这些文件、文档，同时可以达到减少TOKEN消耗的目的（估算有 30%的差距）。

## 切换AI的运行模式（Claude Code专用）

*别一直用默认模式硬扛代码场景！Claude Code 内置多套运行模式，按需切换效率翻倍。*

**绝招：**编写、调试代码时开启 **plan mode on**，让 AI 先规划逻辑再输出；需要 AI 直接修改、补全代码片段时打开 **accept edits on**，一键应用修改；日常对话与简单查询切回默认模式即可。操作也超简单，直接用 **Shift+Tab** 就能快速在各模式间无缝切换，适配不同的编码节奏，既流畅又省 Token。
